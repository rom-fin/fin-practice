# Backend

Здесь будет находиться серверная часть FIN.PRACTICE. Текущий интерфейс в корне проекта пока использует демонстрационные данные из `data.js` и не подключен к API.

При реализации backend сервер должен проверять доступ к платным материалам, хранить прогресс и закладки, обрабатывать учетные записи и подписки. Секреты и исходные учебные материалы не следует добавлять в Git.
