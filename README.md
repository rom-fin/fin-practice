# FIN.PRACTICE

Русскоязычный прототип образовательной платформы для финансовых специалистов. Главная страница, публичные страницы и личный кабинет реализованы на HTML, CSS и JavaScript без сборщика.

Исходный код проекта хранится в [rom-fin/fin-practice](https://github.com/rom-fin/fin-practice). Серверная часть будет развиваться в каталоге [`backend/`](./backend/).

## Запуск

Из корня проекта:

```sh
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Маршруты используют hash-навигацию, например `#/category/fpa` и `#/dashboard`.

## Страницы

- Главная: `#/`
- Направление: `#/category/fpa`, `#/category/ai`, `#/category/cases`, `#/category/acca`
- Тема и кейс: `#/topic/profitability`, `#/case/margin-shift`
- Материалы, тарифы и подготовка оформления: `#/resources`, `#/pricing`, `#/checkout`
- Личный кабинет: `#/dashboard`, `#/dashboard/learning`, `#/dashboard/saved`, `#/dashboard/billing`, `#/dashboard/settings`

Контент для демонстрации находится в [data.js](./data.js). Цвета и размеры интерфейса задаются в [styles.css](./styles.css). Оригинальный векторный логотип находится в [assets/fin-practice-logo.svg](./assets/fin-practice-logo.svg); шрифты Inter и Roboto Condensed используются по лицензии OFL.

## Текущее состояние

Поиск, фильтры, навигация, раскрытие решения демонстрационного кейса и закладки работают в текущей вкладке. Заметки, закладки и учебный прогресс не сохраняются. Формы не отправляют данные. Подписка и оплата недоступны; цены не утверждены. Ограниченные материалы и решения не включены в публичный пакет.

Для рабочего сервиса потребуются серверные интерфейсы входа, каталога и материалов, прогресса и закладок, подписки и проверяемых прав доступа, выставления счетов и подтверждения оплаты, а также приема заявок. Доступ к платному контенту должен проверяться на сервере.
